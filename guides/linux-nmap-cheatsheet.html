Cheat-Sheet

Ab tak jo seekha, sab yahan. Jab bhi koi command bhoolo — yahan dekh lo. Ratna nahi hai, samajhna hai. 🐧

command = jo type karte ho → uske aage uska matlab & full-form

🧭 Ghoomna-phirna (Navigation)

Folders ke andar-bahar jaana, aur dekhna ki kya hai.

pwd
Abhi kis folder me ho, wo dikhata hai Print Working Directory
ls
Is folder ke andar kya-kya hai, list karta hai LiSt
ls -la
Sab dikhata hai — chhupi (hidden) files bhi, details ke saath
cd folder
Us folder ke andar chale jao Change Directory
cd ..
Ek folder peeche/bahar jao
cd ~
Seedha apne home folder me (~ = /home/bhavesh)
cd /
Sabse upar wale root folder me (Linux ki jad)
clear
Screen saaf karo Ctrl + L bhi chalta hai

📄 File & Folder

Banane, padhne, copy, naam badalne aur delete karne ke commands.

mkdir naam
Naya folder banao MaKe DIRectory
touch file.txt
Nayi khaali file banao
echo "text" > file
Ek > = file me text daalo (purana mit jaayega)
echo "text" >> file
Do >> = purane ke neeche jodo (kuch mitta nahi)
cat file.txt
File ke andar kya likha hai, padho conCATenate
cp file copy
File ki copy banao CoPy
mv old new
Naam badlo ya kahin move karo MoVe
rm file.txt
File delete karo ReMove — permanent!

⚙️ System & Install

Admin power aur software install karna (Ubuntu ka "App Store").

sudo ...command
Admin (root) power ke saath chalao — password maangega Super User DO
sudo apt update
Package list refresh — kya-kya naya available hai, pata karo
sudo apt install naam -y
Software install karo (-y = "haan, kar do")
tool --version
Kisi tool ka version check karo (install hua ya nahi)
🔑
Password type karte waqt screen par kuch nahi dikhega — ye normal hai (security ke liye). Bas type karke Enter dabao.

🔍 Nmap — Scanning

Target ke khule "darwaze" (ports) aur unke software dhoondhne ka tool.

nmap target
Target ke khule/band ports scan karo (naam ya IP dono chalega)
nmap -sV target
Har khule port par kaun sa software + version chal raha hai, wo pata karo Service Version
nmap localhost
Apna hi computer scan karo (127.0.0.1) — practice ke liye

Port ki 3 haalat (STATE):

open

Darwaza khula — service chal rahi hai. Hacker ke liye possible entry point.

closed

Darwaza band hai (par wahan hai). Koi service nahi chal rahi.

filtered

Firewall beech me hai — pata nahi chalta khula ya band. Achhi security.

🕵️ Recon Soch — Hacker ka Formula

Version mila? Ab uski kamzori kaise dhoondte hain. Yahi "vulnerability hacking" ka dil hai.

1
Scan karo — nmap -sV se port + software + version nikaalo
2
Research karo — exploit-db.com ya Google par us version ki CVE / known bug dhoondo
3
Range check karo — dekho version sach me kamzor range me hai? (jaise < 6.6 matlab 6.6 se neeche hi kaam karega)
4
Faisla — raasta khula hai ya band. Har port par ye process dohrao.
🧠
Sabse bada lesson: sirf software ka naam match hona kaafi nahi — exact version bhi kamzor range me hona chahiye. Naye log yahi galti karte hain.

⚠️ Galtiyaan jinse bachna hai

  • ✗
    Poora terminal text (prompt + output) paste mat karo — sirf command copy karo. Warna har line "command not found" degi (harmless, par messy).
  • ✗
    rm se delete = permanent — Linux me Recycle Bin nahi hota. Delete se pehle ek baar dekh lo.
  • ✗
    Spelling galti = "command not found" — jaise echoo ya cls. Dhyan se type karo.
🛡️
Golden Rule: Hacking hamesha VM / online lab ke andar. Sirf apne ya likhit-permission wale systems. Kisi aur ka bina permission = illegal (IT Act).
