# 🔐 Zero to Root — My Ethical Hacking Journey

A structured, self-built path from absolute beginner to advanced ethical hacker — theory and hands-on together, no gaps, no shortcuts.

This repository is my personal learning handbook and study material as I work toward becoming a skilled **ethical hacker / penetration tester**.

---

## 📖 The Book — `index.html`

**Zero to Root** is a complete curriculum: **6 Parts, 36 Chapters**, from Linux fundamentals all the way to advanced and modern topics.

| Part | Focus |
|------|-------|
| 1 | Foundations (Linux, networking, scripting) |
| 2 | The pentest methodology (recon → exploit → report) |
| 3 | Core attack domains (web, privesc, passwords, network, Wi-Fi) |
| 4 | Advanced (Active Directory, binary exploitation, crypto, malware) |
| 5 | Modern & emerging (cloud, containers, APIs, AI/LLM security, DevSecOps) |
| 6 | Learner → professional (home lab, CTFs, bug bounty, certs, career) |

Open `index.html` in a browser to read it. Each chapter is written in depth, one at a time, with a lab at the end. Progress is tracked in the page itself.

## 🧭 How to use this

1. **Follow in order.** Each chapter builds on the last.
2. **Understand, don't memorize.** Be able to explain a command before running it.
3. **Type, don't paste.** Mistakes are how it sticks.
4. **Do every lab.** 70% hands-on, 30% reading.

---

## ⚖️ Ethics & Legal

Everything here is for **authorized testing and education only** — my own systems, isolated labs, CTF platforms (OverTheWire, HackTheBox, TryHackMe), or targets with **written permission**.

Accessing any system you do not own or are not authorized to test is illegal (in India, under the **IT Act, 2000**) — and this material must never be used that way. The skill and the ethics are one thing.
